# Mehak's Bio Insights

Create a modern, professional, light-themed personal portfolio website for **Mehak Zahra**, a **Bioinformatics student and aspiring Bioinformatics/AI-ML professional**.



The website should feel **human-designed, elegant, minimal, professional, and authentic** — NOT like a generic AI-generated portfolio template. Avoid excessive gradients, neon colors, glassmorphism, excessive animations, or overly futuristic effects.



## DESIGN & COLOR PALETTE



Use a sophisticated light color scheme:



* Background: `#FAFAF7` — warm off-white

* Primary: `#6B8E7B` — soft sage green

* Accent: `#8FB5A3` — light sage

* Dark headings: `#26332D` — charcoal

* Body text: `#5F6B65`

* Buttons: `#527A67`

* Cards: `#FFFFFF`

* Borders: `#E3E8E4`



Use sage green sparingly for buttons, icons, tags, links, section dividers, and important highlights.



The overall visual hierarchy should be approximately:

**80% neutral/light colors + 20% sage-green accents.**



## TYPOGRAPHY



Use a clean modern font such as **Inter, Manrope, or Plus Jakarta Sans**.



* Large but elegant headings

* Comfortable line spacing

* Strong visual hierarchy

* Avoid overly bold or oversized typography

* Make the website highly readable on both desktop and mobile

# IMPORTANT DESIGN PRINCIPLES



1. Make it look like a **real professional's personal portfolio**, not an AI template.

2. Keep the design light, clean, and spacious.

3. Use sage green only as an accent.

4. Use real content and avoid fake achievements.

5. Do not invent experience, certifications, statistics, or testimonials.

6. Do not use fake skill percentages.

7. Avoid unnecessary gradients.

8. Avoid excessive rounded cards.

9. Use consistent spacing and alignment.

10. Prioritize readability and accessibility.

11. Make every section purposeful.

12. Use subtle scientific/bioinformatics visual elements rather than generic technology graphics.

13. Include clear CTAs for projects and contact.

14. Make all content easy to edit later.

15. Optimize the website for fast loading and SEO.
